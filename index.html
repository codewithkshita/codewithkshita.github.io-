AI / ML · Healthcare

LVH Detection from ECG Signals

A Python-based ML pipeline that automatically flags left ventricular hypertrophy from 12-lead ECG recordings in the PTB-XL dataset.

View on GitHub ↗
  • Cleaned raw ECG signals and extracted morphological features — R-peak/wave detection, R/P/Q/S/T amplitudes, R/S ratio and QRS duration
  • Ran feature selection, then trained and compared Logistic Regression, Random Forest and SVM classifiers
  • Reached a cross-validated AUC of 0.973 with the Random Forest model
